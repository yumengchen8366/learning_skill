## Q1 (10) — Verified computation

**(a)** V dC/dt = R − k V C, C(0) = 0. 单位：左 L·(mg/L)/hr = mg/hr；R = mg/hr；kVC = (1/hr)(L)(mg/L) = mg/hr ✓
等价写法 dC/dt = R/V − kC（每项 mg/L/hr）。

**(b)** C(t) = (R/(kV))(1 − e^{−kt}) = 12 (1 − e^{−0.25t}) mg/L。

**(c)** C_ss = R/(kV) = 120/(0.25·40) = **12 mg/L**。95%：1 − e^{−kt} = 0.95 → t = −ln(0.05)/k = 2.996/0.25 ≈ **12.0 hr ≈ 3 τ**（τ = 1/k = 4 hr）。

**(d)** τ = kt, θ = C/C_ss → **dθ/dτ = 1 − θ, θ(0) = 0**。自然：时间用系统自己的时间常数 1/k 量，浓度用它自己的终值量，于是方程里没有任何参数——所有参数组合下形状相同。

## Q2 (10) — Verified computation

**(a)** M = [[−0.5, 0.1], [0.3, −0.1]] (hr⁻¹)。

**(b)** tr = −0.6, det = 0.05 − 0.03 = 0.02。λ² + 0.6λ + 0.02 = 0 → λ = (−0.6 ± √(0.36 − 0.08))/2 = (−0.6 ± 0.529)/2 → **λ₁ ≈ −0.565 hr⁻¹, λ₂ ≈ −0.0354 hr⁻¹**。

**(c)** τ_fast = 1/0.565 ≈ **1.77 hr**；τ_slow = 1/0.0354 ≈ **28.2 hr**。终末相由 **λ₂ = −0.0354**（绝对值小的）决定。

**(d)** 半对数图是两段直线：初期斜率陡（≈ −0.565，分布相），后期斜率缓（≈ −0.0354，消除相），中间平滑拐。"更 stiff"：两个时间尺度相差 16 倍同时存在（1.8 hr 和 28 hr），一房室只有一个 5 hr；显式求解器步长受最快的 1.8 hr 限制，却要积到 28 hr 的几倍。

## Q3 (8) — Verified computation

**(a)** v = V_max s/(K_m + s)：s = 5 → **0.909 μM/s**；s = 50 → **5 μM/s**；s = 500 → **9.09 μM/s**。

**(b)** s = 5 ≪ K_m：first-order（近似 v ≈ (V_max/K_m)s = 1.0，误差 10%）；s = 50 = K_m：half-saturated，v = V_max/2（一级模型给 10，错一倍）；s = 500 ≫ K_m：zeroth-order，v ≈ V_max（一级模型给 100，错 11 倍）。

**(c)** 不对。v–s 曲线只决定两个数 V_max = k₂e₀ 和 K_m = (k₋₁ + k₂)/k₁；三个常数从两个可观测量里反推不出来（k₋₁ 和 k₂ 永远以和的形式出现）——这是参数可辨识性问题。QSSA 成立条件：**ε = e₀/s₀ ≪ 1**（酶远少于底物，复合物 c 在 ms 级达到准稳态）。

## Q4 (12) — Verified computation

**(a)** dx/dt = 0 → x = 0 或 x + 2y = 3；dy/dt = 0 → y = 0 或 x + y = 2。四个不动点：**(0,0), (3,0), (0,2), (1,1)**。

**(b)** J = [[3 − 2x − 2y, −2x], [−y, 2 − x − 2y]]。

**(c)**
- (0,0): J = diag(3, 2), λ = 3, 2 → **unstable node**
- (3,0): J = [[−3, −6],[0, −1]], λ = −3, −1 → **stable node**
- (0,2): J = [[−1, 0],[−2, −2]], λ = −1, −2 → **stable node**
- (1,1): J = [[−1, −2],[−1, −1]], tr = −2, det = 1 − 2 = **−1 < 0** → **saddle**（λ = −1 ± √2 ≈ 0.414, −2.414）

**(d)** 两个稳定点、中间共存点是鞍点 → 结局取决于**初始条件**落在鞍点分界线（separatrix）哪一侧，最终只有一个种群存活：**competitive exclusion（竞争排斥）**。

**(e)** y 对 x：负反馈（−2xy 项，y 抑制 x）；x 对自身在小 x 时：正反馈（dx/dt ≈ 3x，自我增殖），大 x 时被 −x² 项变成负。

## Q5 (8) — Verified computation

**(a)** C₁ = C₀ + Δt·f(C₀) = 8 + 0.25·(−2·8) = 8(1 − 0.5) = **4.0 mg/L**。精确：8e^{−0.5} = **4.85 mg/L**。Euler 低估（每步按起点斜率直线走）。

**(b)** 稳定条件 Δt < 2/k = **1 hr**。Δt = 1.5：C_n = 8(1 − 3)ⁿ = 8(−2)ⁿ，符号交替、幅值每步翻倍 → **数值不稳定、发散**。（注意 0.5 < Δt < 1 时稳定但震荡、物理上不真实。）

**(c)** 时间常数相差 10⁴ 倍 → stiff。Forward Euler 要 Δt < 2 ms，10 s 需 ≥ **5000 步**（实际为保证精度更多）。改用**隐式方法**（Backward Euler 一类）——MATLAB **ode15s**（或 ode23s）；隐式方法在每步解 x(t+Δt) = x(t) + Δt·f(x(t+Δt))，无条件稳定，步长只受精度限制，快过程衰减完后可以用大步。

## Q6 (10) — Reasoned solution

**(a)** 控制体 [x, x+Δx]，体积 AΔx：AΔx ∂C/∂t = J|ₓ·A − J|ₓ₊Δₓ·A − k C AΔx。除以 AΔx，令 Δx → 0：∂C/∂t = −∂J/∂x − kC；代 J = −D ∂C/∂x：**∂C/∂t = D ∂²C/∂x² − kC**。

**(b)** IC: C(x, 0) = 0, 0 < x < L。BC: **C(0,t) = C₀（Dirichlet）**；**∂C/∂x|_{x=L} = 0（Neumann，无通量）**。

**(c)** [D] = m²/s；[J] = mol/(m²·s)；[k] = 1/s。每项 mol/(m³·s)：D·C/x² = (m²/s)(mol/m³)/m² ✓；kC = (1/s)(mol/m³) ✓。

**(d)** 边界上扩散通量 = 对流带走：**−D ∂C/∂x|_{x=L} = k_c (C(L,t) − 0)** → **Robin（mixed）** 边界条件。（符号：x = L 处流出为正 x 方向，故左边是 −D∂C/∂x。）

## Q7 (12) — Verified computation

**(a)** t_diff = L²/D = (10⁻³)²/(2×10⁻¹⁰) = **5000 s ≈ 83 min**。

**(b)** τ = t/t_diff = 600/5000 = **0.12 ≪ 1** → 扩散前沿还远没到达 L，浓度集中在靠近源的一薄层里，大部分组织里几乎为零。

**(c)** ℓ_diff = √(Dt) = √(2×10⁻¹⁰ × 3600) = 8.5×10⁻⁴ m ≈ **0.85 mm**（还没穿透 1 mm）。

**(d)** 代入 C = C₀ψ, x = Lξ, t = (L²/D)τ：(C₀D/L²) ∂ψ/∂τ = (DC₀/L²) ∂²ψ/∂ξ² − kC₀ψ → **∂ψ/∂τ = ∂²ψ/∂ξ² − (kL²/D) ψ**。无量纲群 **Da = kL²/D = t_diff/t_reaction**（Damköhler 数），这里 = 10⁻⁴ × 10⁻⁶ / 2×10⁻¹⁰ = **0.5**：降解时间尺度（10⁴ s）和扩散时间尺度（5×10³ s）同量级，两者都重要。"同一解"的说法**不再成立**——方程里现在显式含参数 kL²/D，不同药物/组织只要这个组合不同，解就不同（HW3 Q1(d) 里要补的也是：即使纯扩散方程无参数，IC/BC 的无量纲形式也必须相同）。

## Q8 (12) — Verified computation

**(a)** 0 = D d²C/dx² − Q；C(0) = C₀；dC/dx|_{x=L} = 0。

**(b)** 积一次：D dC/dx = Qx + A；用 x = L 处通量为零：A = −QL → dC/dx = (Q/D)(x − L)。再积：C = (Q/D)(x²/2 − Lx) + B；用 C(0) = C₀：B = C₀。
**C(x) = C₀ − (Q/D)(Lx − x²/2)**。

**(c)** dC/dx = (Q/D)(x − L) < 0 对 0 < x < L，所以单调下降，最低在 **x = L**：**C_min = C₀ − QL²/(2D)**。

**(d)** QL²/(2D) = 2×10⁻³ × (2×10⁻⁴)² / (2 × 2×10⁻⁹) = 0.02 → **C_min = 0.18 mol/m³**。
无缺氧条件 C_min ≥ 0 → **L_crit = √(2DC₀/Q)** = √(2 × 2×10⁻⁹ × 0.2 / 2×10⁻³) = √(4×10⁻⁷) ≈ **6.3×10⁻⁴ m = 0.63 mm**。

## Q9 (10) — Reasoned solution

**(a)** N = 5 个内点 + 2 个边界点 = 6 个间隔 → **h = L/6 = 0.5 mm**。∂²C/∂x²|ᵢ ≈ (C_{i+1} − 2Cᵢ + C_{i−1})/h²。

**(b)** dCᵢ/dt = D(C_{i+1} − 2Cᵢ + C_{i−1})/h² − kCᵢ, i = 2,3,4。

**(c)** 节点 1：C₀ = B 是已知常数 → **dC₁/dt = D(C₂ − 2C₁ + B)/h² − kC₁**。
节点 5：Neumann 用一阶差分 (C₆ − C₅)/h = 0 → C₆ = C₅ → **dC₅/dt = D(C₄ − 2C₅ + C₅)/h² − kC₅ = D(C₄ − C₅)/h² − kC₅**。

**(d)** **5 个 ODE**（只对内点；边界点不是未知数），每个初值 Cᵢ(0) = 0。

**(e)** h 减半 → h² 变 1/4 → 扩散项系数 D/h² 变 4 倍 → 系统最快时间常数 ~h²/D 缩为 1/4 → **stiffness 大约增 4 倍**；显式方法的 Δt 上限跟着缩 4 倍。这是 9/23 和 10/14 的连接点：空间网格越细，ODE 系统越 stiff，越需要 ode15s 这类隐式求解器。

## Q10 (8) — Verified computation

RT/F = 8.314 × 310 / 96485 = **26.7 mV**。

**(a)** E_Na = 26.7 ln(145/12) = 26.7 × 2.49 ≈ **+66.6 mV**。
E_Cl（z = −1）= (26.7/(−1)) ln(110/10) = −26.7 × 2.40 ≈ **−64.1 mV**。（E_K = 26.7 ln(5/140) ≈ −89.0 mV ✓ 与课堂一致。）

**(b)** [RT] = (J/(mol·K))·K = J/mol；[zF] = C/mol；比值 = J/C = **V** ✓。

**(c)** 向**正方向、朝 E_Na（≈ +67 mV）**移动——GHK 是各离子 Nernst 电位按通透性加权的"平均"，P_Na 变大，Na⁺ 的权重变大。（这就是动作电位上升支的机制。）

**(d)** 电容电流 + 三支离子电流 = 0：**C_m dV_m/dt = −[g_K(V_m − E_K) + g_Na(V_m − E_Na) + g_Cl(V_m − E_Cl)]**。稳态 dV/dt = 0 → **V_m = (g_K E_K + g_Na E_Na + g_Cl E_Cl)/(g_K + g_Na + g_Cl)** = (1.0×(−89.0) + 0.04×66.6 + 0.45×(−64.1))/1.49 = (−89.0 + 2.66 − 28.8)/1.49 ≈ **−77.3 mV**。
