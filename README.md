# learning-progress

Yumeng 的学习与进步技能，以及持续更新的学习进度记录。

- `learning-progress/`：技能本身（SKILL.md 和参考文件）。在 Claude 设置里安装的就是这个文件夹。
- `progress/current.md`：当前进度摘要。
- `progress/history.md`：每次更新的历史记录。

使用方法：在 Claude 里说“学习”或“进步”，或者在做 PPT、课程学习、导师会议准备时，Claude 会先问是否使用本技能，同意后开始，并在结束时更新 `progress/`。

来源：由 Codex 版 learning-progress v1.1（2026-10-11）改写为 Claude 版。
